# Initial source snapshot: content audit

Checked September 10, 2026, before publication.

## Scope and result

The checked files are the eleven component folders, shared guides and repository
plan, including hidden source files and filenames. No applicant assignments,
source contact details, personal source-account links, local home paths or
membership spreadsheets were found in the package. The original MIT copyright
notice in `rtl-compute/LICENSE` is retained with the copied MAC.

The author’s attribution and current executive-board identities are permitted.
This file-content audit does not prohibit normal Git commit author metadata.
Applicant records, onboarding responses, exclusion decisions and proposed
personnel assignments remain outside the repositories.

## Source and generated files

The local drafting sources are plain folders. Publication uses separate temporary
Git checkouts to create one initial commit per component. Earlier local draft
iterations and reference history are not imported. The source exporter and test
runner do not create commits.

Build outputs and Python caches were removed from the source snapshot. The
technical checks run on a temporary file copy. Run `make clean` from `accelerator`
before sharing later snapshots, since generated outputs can embed local paths.

## Limits

The named org chart, membership analysis, source workbooks and source-reference
files remain separate local material. They are not included in these repositories.
The scan compares known identities from the source records with file contents
and checks email, account and path patterns. It supports a review of this snapshot,
not a guarantee that every possible identifier can be detected automatically.
GitHub accounts, issues and other repositories are outside this content audit.
Repository privacy, commit counts and author attribution are checked separately
when the initial snapshots are published.
